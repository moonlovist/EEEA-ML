A2 · Understand the idea

A row describes one fictional journey. distance_km is measured before prediction; duration_min is observed after the journey. A numerical target defines regression. A finite category defines classification. Grouping records by similarity defines clustering. The identifier names a record; the split column assigns its experimental role. The file contains 48 rows: 28 training, 10 validation and 10 test. The first plot displays training observations.

Python stores a number under a variable name. A list stores several values. Python indexing starts at zero: distances[0] selects the first distance. A function receives an input and returns a result. A scatter plot places distance on the horizontal axis and duration on the vertical axis. Nearby points can have different durations because the data include variation.
