02 · Regression: prediction, error and learning

Calculate MAE by hand, fit a line and compare it with a constant baseline on validation data.

0–10 min: predict; 10–25: worked example; 25–45: guided run; 45–65: one change; 65–80: interpret; 80–90: explain and submit.

Predict

For observed durations [12, 19, 32] and predictions [10, 20, 30], calculate the three absolute errors. Estimate their average before running the cell.

Understand

The affine model predicts y_hat = w*x + b. Its slope w has unit min/km and its intercept b has unit min. The residual is prediction minus observation: e_i = y_hat_i - y_i. Absolute error is |e_i|. MAE = (|e_1| + ... + |e_n|)/n, expressed in minutes.

LinearRegression fits w and b by minimizing the sum of squared training residuals, with an intercept. Evaluation here uses validation MAE. The baseline predicts the training mean for every validation journey. Fitting and evaluation therefore have distinct roles. A change to a manual line changes its predictions; training estimates parameters from the training data.

Follow the code

observed = np.array([12., 19., 32.])
predicted = np.array([10., 20., 30.])
absolute_errors = np.abs(predicted - observed)
print(absolute_errors, absolute_errors.mean())
from sklearn.linear_model import LinearRegression
sets = split_data("walks.csv")
X_train, y_train = sets["train"]
model = LinearRegression().fit(X_train, y_train)
print("w, b:", model.coef_[0], model.intercept_)
print("2 km:", model.predict([[2.]]))

Absolute errors are [2, 1, 2], hence MAE = 5/3 ≈ 1.667 min. In the supplied reference run, the fitted slope is about 11.281 and validation MAE about 2.569 min. Read the exact numbers and software versions in the result page.

Predict

Understand

The fixed fictional classification data contain two numerical coordinates and a label, 0 or 1. There are 96 training, 48 validation and 48 reserved test observations. kNN assigns the majority class among k nearby training points. The pipeline estimates feature means and scales on training data before measuring distances. A decision tree successively compares features with thresholds. Accuracy = correct predictions / evaluated observations. A confusion matrix uses true labels as rows and predicted labels as columns in this course. 04 · Generalisation: choose a model fairly

Use training for fitting, validation for selection and the reserved test for final evaluation. Recognise overfitting in a curve.

0–10 min: predict; 10–25: worked example; 25–45: guided run; 45–65: one change; 65–80: interpret; 80–90: explain and submit.

Notebook · read and open · Measured example and figures

Predict

A model scores 100% on training and 81% on validation. Another scores 89% and 83%. Which result helps select between these models? Explain before running.

Understand

Model complexity controls the set of patterns a model can express. Increasing tree depth can improve its fit to individual training observations. Generalisation concerns performance on further observations from the relevant population. A gap between high training performance and weaker validation performance is evidence to examine for overfitting.

The selection rule here is fixed in advance: highest validation accuracy, with the shallower candidate selected in a tie. Standardisation parameters and other fitted preprocessing belong to the training stage. A feature must be available at the intended prediction time: the final observed duration would reveal the answer when predicting whether a journey exceeds 25 minutes. That is target leakage.

Follow the code

from sklearn.tree import DecisionTreeClassifier
sets = split_data()
for depth in [1, 2, 3, 5, 10]:
    tree = DecisionTreeClassifier(max_depth=depth, random_state=7)
    tree.fit(*sets["train"])
    print(depth, tree.score(*sets["train"]), tree.score(*sets["validation"]))

The supplied curve reaches training accuracy 1.0 at large depth. The first maximum validation accuracy occurs at depth 2; depth 3 ties it. The fixed tie rule selects depth 2. Read the actual table if your environment produces a different measured result.

Predict

Two records differ by 1 monthly visit and EUR 100 of monthly spending. Which feature contributes more to their raw squared Euclidean distance?

Understand

Raw squared distance is the sum of coordinate differences squared. Here the contributions are 1² and 100², giving 10001. Standardisation transforms x to z=(x−mean)/sd. StandardScaler uses population standard deviation: sd = sqrt(sum((x_i−mean)²)/n). On [1,3], mean=2, sd=1, so 3 becomes 1.

K-means alternates assignment to a nearest centre and replacement of each centre by its assigned mean. Its objective, inertia, is the sum of squared within-cluster distances. The chosen scaling defines the geometry. Compare inertia values within the same feature space. Silhouette also depends on that geometry. Cluster IDs are arbitrary names. Here clustering explores all 90 fictional customers; assessing future-customer assignment would require a separate held-out protocol.

Follow the code

values = np.array([1., 3.])
mean = values.mean()
sd = values.std(ddof=0)
print("mean, sd:", mean, sd)
print("z:", (values - mean) / sd)
print("raw squared distance:", 1**2 + 100**2)
from sklearn.preprocessing import StandardScaler
rows = read_rows("customers.csv")
X = np.array([[float(r["visits_month"]), float(r["spend_eur_month"])] for r in rows])
scaler = StandardScaler().fit(X)
print("standardised means:", scaler.transform(X).mean(axis=0))

The two standardised values are −1 and 1. Standardised feature means are approximately zero; tiny floating-point residuals are expected. Plot axes and reported centres remain in visits/month and EUR/month for interpretation.

06 · Neural networks: forward pass, gradient and learning

Trace a small neural network, count its parameters and relate gradient updates to loss curves.

Predict

For f(x)=3x³+2x²+5, calculate f(2). Using f′(x)=9x²+4x, predict f′(2). What does a positive derivative say about a sufficiently small move in x?

Understand

Our MLP has two inputs, eight tanh hidden units and one sigmoid output for class-1 probability. Its 33 parameters are 2×8 input weights, 8 hidden biases, 8 output weights and 1 output bias. Forward computation is a=XW1+b1, h=tanh(a), z=hW2+b2, p=sigmoid(z).

For labels y in {0,1}, mean binary cross-entropy is L=−mean[y log(p)+(1−y)log(1−p)]. The code evaluates the equivalent stable expression mean[log(1+exp(z))−yz]. The chain rule gives dL/dz=(p−y)/n. Then dW2=hᵀ(dL/dz), db2=sum(dL/dz), da=((dL/dz)W2ᵀ)⊙(1−h²), dW1=Xᵀda and db1=sum_rows(da). Each parameter updates as parameter−rate×gradient, using gradients computed at the same old parameter values. Each update uses all 96 training rows. Scaling is fitted on those rows.

Follow the code

x = 2.0
f = 3*x**3 + 2*x**2 + 5
derivative = 9*x**2 + 4*x
print("f(2), derivative:", f, derivative)
from models import half_mse_gradient, TinyMLP
loss, dw, db = half_mse_gradient([1,2,3], [12,19,32], 10, 0)
print("loss, dw, db:", loss, dw, db)
print("one update:", 10 - .1*dw, 0 - .1*db)
print("MLP parameters:", TinyMLP(width=8).parameters)

f(2)=37 and f′(2)=44. For the affine half-MSE example, L=1.5, dw=−2, db=−1; a rate of 0.1 gives w=10.2 and b=0.1. The supplied MLP run reduces training BCE from about 0.553 to 0.352 over 300 updates. Compare validation loss as well.

07 · Generation and attention in small examples

Compute a next-token probability, generate a short sequence and read a causal attention matrix.

0–10 min: predict; 10–25: worked example; 25–45: guided run; 45–65: one change; 65–80: interpret; 80–90: explain and submit.

Notebook · read and open · Measured example and figures

Predict

The word a is followed by book 3 times and note 4 times in the English corpus. What are the two empirical next-token probabilities?

Understand

The local corpus contains seven short fictional sentences per language. A token is a whitespace-separated word in this experiment. A bigram model estimates the next word using the current word: P(next|current)=count(current,next)/sum_next count(current,next). Generation repeatedly samples a next token and appends it until END or the 12-new-token budget. The model represents local word-pair counts. Its generated sentences provide examples for discussing repetition, coherence and factual support.

Temperature transforms positive probabilities as p_T(i)=p(i)^(1/T)/sum_j p(j)^(1/T). A smaller positive T favours the more probable token. The attention calculation is a separate fixed numerical example: scores=QKᵀ/sqrt(d), mask future positions, apply row-wise softmax, then multiply by V. Each row sums to 1 and future-position weights equal 0. This demonstrates a Transformer building block; the word generator uses the bigram probabilities.

Follow the code

import json
from models import Bigram, causal_attention
sentences = json.loads((ROOT / "data" / "corpus.json").read_text(encoding="utf-8"))[LANG]
model = Bigram(sentences)
context = "a" if LANG == "en" else "un"
tokens, probabilities = model.distribution(context)
print(list(zip(tokens, probabilities)))
Q = np.array([[1.,0.], [0.,1.], [1.,1.]])
V = np.array([[10.,0.], [0.,10.], [10.,10.]])
attention_output, weights = causal_attention(Q, Q, V)
print(weights)
print("row sums:", weights.sum(axis=1))

The probabilities are 3/7 and 4/7. The first attention row is [1,0,0], so its output equals V[0]=[10,0]. The second row is approximately [0.33024,0.66976,0]. At T=0.5, the two probabilities become 9/25 and 16/25.
