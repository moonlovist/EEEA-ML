Windows · Installation pas à pas

Choisir un point de départ

Commencer par l’observation hors ligne : ouvrir le manuel et un exemple mesuré dans le navigateur, prédire un résultat et discuter une figure. Utiliser ensuite Python pour reproduire et modifier l’expérience. Les données sont fournies et les modèles utilisent le processeur.

Prévoir 30 à 45 minutes d’installation à la première séance si Python est nouveau. L’enseignant peut préparer les postes avant le cours. Ouvrir un Notebook et son onglet à la fois. Les expériences utilisent au maximum 192 observations de classification, 48 trajets ou 90 clients ; le réseau possède 33 paramètres dans sa configuration initiale.

  1. Télécharger ML_Labs_2026_student.zip.
  2. Ouvrir l’Explorateur avec Windows+E. Saisir %USERPROFILE% dans la barre d’adresse. Créer AI_Course.
  3. Clic droit sur le ZIP → Extraire tout. Extraire dans AI_Course. Ouvrir le dossier ML_Labs_2026.
  4. Double-cliquer sur START_HERE.html. Choisir Français, puis le manuel ou les premiers pas Python.
  5. Activer Afficher → Afficher → Extensions de noms de fichiers sous Windows 11, ou Affichage → Extensions de noms de fichiers sous Windows 10.

Les guides et les 16 résultats de référence et les 12 résultats après modification sont maintenant consultables hors ligne. Ce parcours utilise des résultats d’exécutions réelles du code ; chaque rapport indique ses versions logicielles.

1. Ouvrir le terminal dans le bon dossier

Dans le dossier extrait ML_Labs_2026, cliquer sur la barre d’adresse, saisir cmd, puis Entrée. Exécuter :

dir
py -3.13 --version

La liste contient RUN.cmd, course.py, requirements-core.txt et notebooks. Exécuter une commande par ligne. L’invite de commandes affiche un chemin terminé par > ; l’interpréteur Python affiche >>>. Dans ce dernier cas, saisir exit() pour revenir à l’invite de commandes.

2. Installer ou réutiliser Python

La cible de la salle est CPython 3.13 standard 64 bits sous Windows x64. Des installations Python 3.11 ou 3.12 existantes peuvent aussi utiliser les dépendances proposées. L’installation Python du cours d’agents peut être réutilisée ; ce cours de ML possède son propre environnement virtuel.

  1. Lire Paramètres → Système → Informations système → Type du système. Identifier x64 ou ARM64. Le parcours de paquets Windows fixé cible x64. Pour ARM64 ou un poste administré, l’enseignant choisit et vérifie un environnement compatible.
  2. Ouvrir les versions Python pour Windows. Ouvrir la version corrective 3.13 maintenue retenue par l’enseignant, puis Files.
  3. Choisir Windows installer (64-bit) pour x64. Utiliser une distribution CPython standard.
  4. Installer pour l’utilisateur courant. Cocher Add python.exe to PATH. Conserver pip et IDLE. Si l’option du lanceur pour tous les utilisateurs demande des droits administrateur, choisir une configuration personnelle.
  5. Fermer le terminal et le rouvrir depuis le dossier du cours. Vérifier py -3.13 --version.

Le technicien peut préinstaller Python sur les postes administrés. L’installateur complet et le ZIP peuvent être distribués sur clé USB.

3. Créer une fois l’environnement du cours

RUN.cmd -m venv .venv
.venv\Scripts\python.exe --version

L’environnement virtuel est un dossier local contenant l’accès à l’interpréteur et les paquets du cours. La seconde commande affiche la version choisie. Les séances suivantes réutilisent ce dossier. L’appel direct à son exécutable relie chaque commande au même environnement.

Installer les outils numériques :

.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements-core.txt
RUN.cmd course.py doctor

Diagnostic final attendu : status: READY, avec les versions des paquets. L’installation télécharge des paquets précompilés et leurs dépendances. Garder le terminal ouvert jusqu’à la fin. INSTALL_CORE.cmd effectue la même installation après création de l’environnement.

Les versions cibles figurent dans requirements-core.txt. Les exemples mesurés fournis ont été produits sous macOS avec Python 3.8.20, NumPy 1.24.4, SciPy 1.10.1, scikit-learn 1.3.2 et Matplotlib 3.7.4. L’installation Windows avec les versions cibles constitue une étape de validation par l’enseignant. Consigner les versions de chaque exécution pour comparer les valeurs numériques.

4. Exécuter une première expérience par le terminal

RUN.cmd course.py lab 1 --lang fr

Le terminal affiche un résumé et le chemin de outputs/fr/lab01/report.html. Ouvrir ce fichier dans le navigateur. Effectifs attendus : 48 trajets, répartis en 28 lignes d’entraînement, 10 de validation et 10 de test. Le graphique montre les trajets d’entraînement.

Essayer cet exemple après la séance correspondante :

RUN.cmd course.py lab 3 --lang fr --neighbors 1

Cette commande change k dans kNN, en conservant découpage et réglage de l’arbre. Enregistrer chaque comparaison dans un dossier distinct pour conserver les deux essais :

RUN.cmd course.py lab 3 --lang fr --neighbors 1 --output-dir outputs/comparison_k1

5. Installer et ouvrir Jupyter Notebook

.venv\Scripts\python.exe -m pip install --only-binary=:all: -r requirements-notebook.txt
RUN.cmd -m notebook

Le terminal démarre un service local et ouvre habituellement un onglet. Si nécessaire, copier l’URL locale affichée, avec son token, dans votre navigateur. Garder le terminal ouvert pendant la séance.

  1. Dans le navigateur de fichiers Jupyter, ouvrir notebooks → fr → Lab00_FR.ipynb.
  2. Sélectionner la première cellule de code. Appuyer sur Maj+Entrée. Le résultat apparaît dessous.
  3. Lire une cellule de texte, prédire la suite, puis exécuter la cellule de code suivante.
  4. Une cellule marquée [*] est en cours. Attendre son numéro d’exécution.
  5. Modifier une valeur d’exercice et relancer cette cellule. Enregistrer avec Ctrl+S.
  6. À la fin, utiliser Kernel → Restart Kernel and Run All pour vérifier une exécution du début à la fin. Le libellé dépend de la langue de l’interface.
  7. Ouvrir Lab01 après l’échauffement. Aux séances suivantes, ouvrir le Notebook correspondant et exécuter sa cellule de préparation en premier.

Après installation, START_NOTEBOOK.cmd lance aussi l’interface. Les cellules Markdown contiennent du texte ; les cellules Code exécutent Python. Une réponse None marque un exercice à compléter. Son retour pédagogique est indépendant des cellules du modèle.

Pour terminer, enregistrer le Notebook, arrêter son noyau depuis l’interface, puis arrêter le serveur avec Ctrl+C dans le terminal et confirmer si demandé.

6. Connexion limitée ou salle hors ligne

L’enseignant peut préparer un wheelhouse sur un Windows x64 avec la même version de Python, puis le copier avec le ZIP. Installer depuis ce dossier :

.venv\Scripts\python.exe -m pip install --no-index --find-links wheelhouse -r requirements-notebook.txt

Une fois installés, les exercices utilisent les CSV et JSON locaux. Pendant une difficulté de configuration, poursuivre avec les graphiques, les premiers pas Python et les calculs manuels. Conserver les prédictions pour les comparer à une exécution ultérieure.
