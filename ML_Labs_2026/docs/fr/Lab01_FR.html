A2 · Comprendre l’idée

Une ligne décrit un trajet fictif. distance_km est connu avant la prédiction ; duration_min est observé après le trajet. Une cible numérique définit une régression. Une catégorie définit une classification. Le regroupement par similarité définit le clustering. L’identifiant nomme une observation ; split lui attribue un rôle expérimental. Le fichier contient 48 lignes : 28 d’entraînement, 10 de validation et 10 de test. Le premier graphique montre les observations d’entraînement.

Python associe un nom de variable à une valeur. Une liste contient plusieurs valeurs. Les indices commencent à zéro : distances[0] sélectionne la première distance. Une fonction reçoit une entrée et renvoie un résultat. Le nuage de points place la distance horizontalement et la durée verticalement. Des points proches peuvent avoir des durées différentes, car les données contiennent de la variation.
