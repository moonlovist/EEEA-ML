02 · Régression : prédiction, erreur et apprentissage

Calculer la MAE à la main, ajuster une droite et la comparer à une référence constante sur la validation.

0–10 min : prédire ; 10–25 : exemple guidé ; 25–45 : exécuter ; 45–65 : une modification ; 65–80 : interpréter ; 80–90 : expliquer et rendre.

Prédire

Pour les durées observées [12, 19, 32] et les prédictions [10, 20, 30], calculer les trois erreurs absolues. Estimer leur moyenne avant l’exécution.

Comprendre

Le modèle affine prédit y_hat = w*x + b. La pente w s’exprime en min/km et l’ordonnée b en minutes. Le résidu est prédiction moins observation : e_i = y_hat_i - y_i. L’erreur absolue vaut |e_i|. MAE = (|e_1| + ... + |e_n|)/n, en minutes.

LinearRegression ajuste w et b en minimisant la somme des résidus d’entraînement au carré, avec une constante. L’évaluation emploie ici la MAE de validation. Le modèle de référence prédit la moyenne d’entraînement pour chaque trajet de validation. Ajustement et évaluation ont donc des rôles distincts. Modifier une droite manuelle change ses prédictions ; l’apprentissage estime les paramètres à partir des observations d’entraînement.

Suivre le code

observed = np.array([12., 19., 32.])
predicted = np.array([10., 20., 30.])
absolute_errors = np.abs(predicted - observed)
print(absolute_errors, absolute_errors.mean())
from sklearn.linear_model import LinearRegression
sets = split_data("walks.csv")
X_train, y_train = sets["train"]
model = LinearRegression().fit(X_train, y_train)
print("w, b:", model.coef_[0], model.intercept_)
print("2 km:", model.predict([[2.]]))

Les erreurs absolues valent [2, 1, 2], donc MAE = 5/3 ≈ 1,667 min. Dans l’exécution fournie, la pente ajustée vaut environ 11,281 et la MAE de validation environ 2,569 min. Lire les valeurs précises et les versions logicielles sur la page de résultats.

Prédire

Cinq prédictions sur six correspondent aux étiquettes. Calculer l’exactitude. Que peut-il se passer près d’une frontière où les deux classes apparaissent ?

Comprendre

Les données fictives fixées contiennent deux coordonnées numériques et une étiquette 0 ou 1. Elles comprennent 96 observations d’entraînement, 48 de validation et 48 réservées au test. kNN attribue la classe majoritaire parmi k points d’entraînement proches. Le pipeline estime moyennes et échelles sur l’entraînement avant de mesurer les distances. Un arbre compare successivement des variables à des seuils. Sa profondeur maximale borne le nombre de comparaisons sur un chemin.

Exactitude = prédictions correctes / observations évaluées. Dans ce cours, les lignes de la matrice de confusion représentent les vraies classes et les colonnes les classes prédites. La diagonale compte les réussites ; les autres cases décrivent les erreurs. Le fond du graphique représente les classes prédites ; les couleurs des points indiquent les classes observées.

Suivre le code

from sklearn.metrics import accuracy_score, confusion_matrix

Comprendre

La généralisation concerne les performances sur de nouvelles observations de la population pertinente. La règle de sélection est fixée à l’avance : meilleure exactitude de validation, puis candidat le moins profond en cas d’égalité. Prédire

Deux observations diffèrent d’une visite mensuelle et de 100 EUR de dépense mensuelle. Quelle variable contribue davantage à leur distance euclidienne brute au carré ?

Comprendre

La distance brute au carré est la somme des différences de coordonnées au carré. Les contributions valent ici 1² et 100², soit 10001. La standardisation transforme x en z=(x−moyenne)/écart-type. StandardScaler utilise l’écart-type de population : sd = sqrt(sum((x_i−moyenne)²)/n). Pour [1,3], la moyenne vaut 2, sd vaut 1 et 3 devient 1.

K-means alterne affectation au centre le plus proche et remplacement de chaque centre par la moyenne des points affectés. Son objectif, l’inertie, est la somme des distances internes au carré. L’échelle choisie définit la géométrie. Comparer les inerties dans un même espace de variables. La silhouette dépend aussi de cette géométrie. Les identifiants de groupe sont arbitraires. L’expérience explore les 90 clients fictifs ; évaluer l’affectation de futurs clients demanderait un protocole réservé distinct.

Suivre le code

values = np.array([1., 3.])
mean = values.mean()
sd = values.std(ddof=0)
print("mean, sd:", mean, sd)
print("z:", (values - mean) / sd)

Les deux valeurs standardisées sont −1 et 1. Les moyennes des variables standardisées sont proches de zéro ; de petits résidus numériques sont attendus. Axes et centres restent exprimés en visites/mois et EUR/mois pour l’interprétation.

06 · Réseaux : propagation, gradient et apprentissage

Suivre un petit réseau, compter ses paramètres et relier les mises à jour aux courbes de perte.

Prédire

Pour f(x)=3x³+2x²+5, calculer f(2). Avec f′(x)=9x²+4x, prédire f′(2). Que signifie une dérivée positive pour un déplacement suffisamment petit de x ?

Comprendre

Le MLP possède deux entrées, huit unités cachées tanh et une sortie sigmoïde donnant la probabilité de classe 1. Ses 33 paramètres comprennent 2×8 poids d’entrée, 8 biais cachés, 8 poids de sortie et 1 biais final. Le calcul direct est a=XW1+b1, h=tanh(a), z=hW2+b2, p=sigmoid(z).

Pour y dans {0,1}, l’entropie croisée binaire moyenne vaut L=−mean[y log(p)+(1−y)log(1−p)]. Le code évalue la forme stable équivalente mean[log(1+exp(z))−yz]. La règle de chaîne donne dL/dz=(p−y)/n. Puis dW2=hᵀ(dL/dz), db2=sum(dL/dz), da=((dL/dz)W2ᵀ)⊙(1−h²), dW1=Xᵀda et db1=sum_rows(da). Chaque paramètre devient paramètre−pas×gradient, avec tous les gradients calculés aux mêmes anciennes valeurs. Chaque mise à jour utilise les 96 lignes d’entraînement ; la standardisation est ajustée sur ces lignes.

Suivre le code

x = 2.0
f = 3*x**3 + 2*x**2 + 5
derivative = 9*x**2 + 4*x
print("f(2), derivative:", f, derivative)
from models import half_mse_gradient, TinyMLP
loss, dw, db = half_mse_gradient([1,2,3], [12,19,32], 10, 0)
print("loss, dw, db:", loss, dw, db)
print("one update:", 10 - .1*dw, 0 - .1*db)
print("MLP parameters:", TinyMLP(width=8).parameters)

f(2)=37 et f′(2)=44. Pour la demi-MSE affine, L=1,5, dw=−2, db=−1 ; un pas de 0,1 donne w=10,2 et b=0,1. Le MLP fourni fait passer la BCE d’entraînement d’environ 0,553 à 0,352 en 300 mises à jour. Examiner aussi la perte de validation.

07 · Génération et attention sur de petits exemples

Calculer une probabilité du prochain token, générer une courte séquence et lire une matrice d’attention causale.

Prédire

Le mot un est suivi de livre 3 fois et de texte 4 fois dans le corpus français. Quelles sont les deux probabilités empiriques du prochain token ?

Comprendre

Le corpus local contient sept courtes phrases fictives par langue. Un token est ici un mot séparé par des espaces. Le modèle bigramme estime le prochain mot à partir du mot courant : P(suivant|courant)=compte(courant,suivant)/somme_suivants compte(courant,suivant). La génération tire un token, l’ajoute et recommence jusqu’à END ou au budget de 12 nouveaux tokens. Le modèle représente les comptes de paires de mots. Les phrases permettent de discuter répétition, cohérence et appui factuel.

La température transforme les probabilités positives : p_T(i)=p(i)^(1/T)/somme_j p(j)^(1/T). Un T positif plus petit favorise le token le plus probable. L’attention constitue un calcul numérique distinct : scores=QKᵀ/sqrt(d), masquage du futur, softmax par ligne, puis multiplication par V. Chaque ligne somme à 1 et les poids futurs valent 0. Ce calcul illustre un composant du Transformer ; le générateur de mots utilise les probabilités bigrammes.

Suivre le code

import json
from models import Bigram, causal_attention
sentences = json.loads((ROOT / "data" / "corpus.json").read_text(encoding="utf-8"))[LANG]
model = Bigram(sentences)
context = "a" if LANG == "en" else "un"
tokens, probabilities = model.distribution(context)
print(list(zip(tokens, probabilities)))
Q = np.array([[1.,0.], [0.,1.], [1.,1.]])
V = np.array([[10.,0.], [0.,10.], [10.,10.]])
attention_output, weights = causal_attention(Q, Q, V)
print(weights)
print("row sums:", weights.sum(axis=1))

Les probabilités valent 3/7 et 4/7. La première ligne d’attention est [1,0,0], donc sa sortie vaut V[0]=[10,0]. La deuxième ligne vaut environ [0,33024,0,66976,0]. Pour T=0,5, les deux probabilités deviennent 9/25 et 16/25.
