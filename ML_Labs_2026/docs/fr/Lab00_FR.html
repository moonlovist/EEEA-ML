Ouvrir ce TP dans Jupyter

  1. Extraire tout le dossier ML_Labs_2026 depuis le ZIP.
  2. À la première utilisation, suivre le guide Windows pour installer Python, créer .venv et installer Jupyter.
  3. Dans l’Explorateur Windows, ouvrir ML_Labs_2026 et double-cliquer sur START_NOTEBOOK.cmd. Garder le terminal ouvert.

  5. Sélectionner la première cellule de code, puis appuyer sur Maj+Entrée. Exécuter les cellules dans l’ordre. Ctrl+S enregistre le travail.
