## What you will do

- **D1–D3:** follow a linear update, train a logistic classifier, and read the confusion matrix, ROC and PR.
- **E1–E4:** implement an update function, a training function, classification metrics, and validation-based threshold selection followed by held-out testing.
- **B1–B3:** compare learning rates, reconstruct ROC, and investigate class imbalance.

For local Jupyter setup, follow **[START.txt](START.txt)** in the extracted **lab** folder. The notebooks include their data and require no API key or GPU. [Data dictionary](data/DATA.txt).
