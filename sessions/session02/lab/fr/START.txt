Installation locale (Python 3.10+ recommandé), dans un terminal du dossier :
python -m pip install -r requirements.txt
python -m notebook
Sous Windows, si Python est accessible par le lanceur py, remplacer python par py dans les deux commandes.
Utiliser un environnement Python fonctionnel déjà configuré si disponible.

Dans Colab : Fichier > Importer un notebook, puis se connecter à un environnement Python. Enregistrer/télécharger le notebook avant de quitter.
Aucun GPU ni clé API. Toutes les données sont incluses. Les CSV de data/ sont facultatifs.
Le notebook de démonstration contient les exemples résolus. Le notebook d’exercices contient volontairement des fonctions TODO à compléter.
